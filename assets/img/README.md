# Images

Drop real photos here — the site picks them up by filename, no code changes needed.

| File                 | Used for                          | Suggested size            |
| -------------------- | --------------------------------- | ------------------------- |
| `beth-portrait.jpg`  | Hero portrait                     | 1000 × 1250 (4:5 portrait) |
| `og-image.jpg`       | Link preview when shared          | 1200 × 630                |
| `apple-touch-icon.png` | iOS home-screen icon            | 180 × 180                 |
| `favicon.svg`        | Browser tab icon (already present) | —                         |

If `beth-portrait.jpg` is missing, the hero falls back to a styled placeholder
automatically, so the page never shows a broken image.

Keep JPEGs under ~300 KB — run them through [squoosh.app](https://squoosh.app)
before committing.
